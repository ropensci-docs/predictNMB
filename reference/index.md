# Package index

## All functions

- [`autoplot(`*`<predictNMBscreen>`*`)`](https://docs.ropensci.org/predictNMB/reference/autoplot.predictNMBscreen.md)
  : Create plots of from screened predictNMB simulations.

- [`autoplot(`*`<predictNMBsim>`*`)`](https://docs.ropensci.org/predictNMB/reference/autoplot.predictNMBsim.md)
  : Create plots of from predictNMB simulations.

- [`ce_plot()`](https://docs.ropensci.org/predictNMB/reference/ce_plot.md)
  : Create a cost-effectiveness plot.

- [`ce_plot(`*`<predictNMBsim>`*`)`](https://docs.ropensci.org/predictNMB/reference/ce_plot.predictNMBsim.md)
  : Create a cost-effectiveness plot.

- [`do_nmb_sim()`](https://docs.ropensci.org/predictNMB/reference/do_nmb_sim.md)
  : Do the predictNMB simulation, evaluating the net monetary benefit
  (NMB) of the simulated model.

- [`evaluate_cutpoint_cost()`](https://docs.ropensci.org/predictNMB/reference/evaluate_cutpoint_cost.md)
  : Evaluates a cutpoint by returning the mean treatment cost per
  sample.

- [`evaluate_cutpoint_nmb()`](https://docs.ropensci.org/predictNMB/reference/evaluate_cutpoint_nmb.md)
  : Evaluates a cutpoint by returning the mean NMB per sample.

- [`evaluate_cutpoint_qalys()`](https://docs.ropensci.org/predictNMB/reference/evaluate_cutpoint_qalys.md)
  : Evaluates a cutpoint by returning the mean QALYs lost per sample.

- [`get_inbuilt_cutpoint()`](https://docs.ropensci.org/predictNMB/reference/get_inbuilt_cutpoint.md)
  : Get a cutpoint using the methods inbuilt to predictNMB

- [`get_inbuilt_cutpoint_methods()`](https://docs.ropensci.org/predictNMB/reference/get_inbuilt_cutpoint_methods.md)
  : Get a vector of all the inbuilt cutpoint methods

- [`get_nmb_sampler()`](https://docs.ropensci.org/predictNMB/reference/get_nmb_sampler.md)
  :

  Make a NMB sampler for use in
  [`do_nmb_sim()`](https://docs.ropensci.org/predictNMB/reference/do_nmb_sim.md)
  or
  [`screen_simulation_inputs()`](https://docs.ropensci.org/predictNMB/reference/screen_simulation_inputs.md)

- [`get_sample()`](https://docs.ropensci.org/predictNMB/reference/get_sample.md)
  : Samples data for a prediction model with a specified AUC and
  prevalence.

- [`get_thresholds()`](https://docs.ropensci.org/predictNMB/reference/get_thresholds.md)
  : Gets probability thresholds given predicted probabilities, outcomes
  and NMB.

- [`print(`*`<predictNMBscreen>`*`)`](https://docs.ropensci.org/predictNMB/reference/print.predictNMBscreen.md)
  : Print a summary of a predictNMBscreen object

- [`print(`*`<predictNMBsim>`*`)`](https://docs.ropensci.org/predictNMB/reference/print.predictNMBsim.md)
  : Print a summary of a predictNMBsim object

- [`screen_simulation_inputs()`](https://docs.ropensci.org/predictNMB/reference/screen_simulation_inputs.md)
  :

  Screen many simulation inputs: a parent function to
  [`do_nmb_sim()`](https://docs.ropensci.org/predictNMB/reference/do_nmb_sim.md)

- [`summary(`*`<predictNMBscreen>`*`)`](https://docs.ropensci.org/predictNMB/reference/summary.predictNMBscreen.md)
  :

  Create table summaries of `predictNMBscreen` objects.

- [`summary(`*`<predictNMBsim>`*`)`](https://docs.ropensci.org/predictNMB/reference/summary.predictNMBsim.md)
  :

  Create table summaries of `predictNMBsim` objects.

- [`theme_sim()`](https://docs.ropensci.org/predictNMB/reference/theme_sim.md)
  :

  Returns a `ggplot2` theme that reduces clutter in an
  [`autoplot()`](https://ggplot2.tidyverse.org/reference/autoplot.html)
  of a `predictNMBsim` object.
